Le mode operatoire de chaque action

A1 Geler les ecritures

La veille au soir, l exploitant suspend les traitements planifies de comptabilite, verifie qu aucune ecriture n est en cours dans le journal, puis pose le drapeau de gel sur la base de production ; en cas d echec, il previent le responsable de la bascule avant minuit.

A2 Sauvegarder la base

L exploitant lance la sauvegarde complete de la base de production, controle la taille du fichier obtenu contre celle de la veille, copie la sauvegarde sur le second site et consigne son empreinte dans le registre de bascule avant de donner la main a l integrateur.

A3 Deployer la version

L integrateur deploie l image validee en recette, rejoue les migrations de schema dans l ordre du lot, verifie la page de sante de chaque service puis lance les trois parcours de controle ; un parcours rouge declenche le retour arriere sans attendre de decision.

A4 Rouvrir les ecritures

Une fois les parcours verts, l exploitant retire le drapeau de gel, relance les traitements planifies suspendus la veille, surveille la premiere heure de journal et transmet le compte rendu de bascule au responsable avec l empreinte de la sauvegarde et la version deployee.

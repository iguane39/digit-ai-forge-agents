Note de cadrage du lot douze

Recette

Le lot douze est entre en recette le deux septembre sur trois environnements : le poste local, la plateforme d integration et la preproduction, avec les memes jeux de donnees.

Echecs

Les deux echecs releves en integration portent sur le meme composant et ont ete corriges le trois septembre, la recette etant rejouee le meme jour sans aucun echec.

Migration

La migration de la base est planifiee le vingt septembre, le decommissionnement suit le vingt-sept, et la bascule reste reversible pendant huit jours pleins.

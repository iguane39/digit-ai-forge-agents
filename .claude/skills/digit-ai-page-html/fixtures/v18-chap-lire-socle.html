Note de cadrage du lot douze

Le lot douze est entre en recette le deux septembre, sur trois environnements : le poste local, la plateforme d integration et la preproduction. Les releves proviennent du journal d execution archive au meme dossier que cette note, et ils ont ete pris deux fois a deux jours d intervalle pour mesurer la stabilite du temps de construction. La duree du build a augmente de quarante secondes entre le lot onze et le lot douze, pour une cause connue : le lot douze ajoute quarante tests, et le cout unitaire par test reste stable a une virgule deux seconde. Aucune action n est demandee sur ce point, la mesure servant de repere pour le lot suivant.

Les deux echecs releves en integration portent sur le meme composant. Le premier vient d un fuseau horaire code en dur, que le poste local ne montre pas puisqu il tourne en temps universel ; le second vient d un fichier absent du depot. Les deux ont ete corriges le trois septembre et la recette rejouee le meme jour, sans echec sur les trois environnements. La migration de la base est planifiee le vingt septembre, le decommissionnement suit le vingt-sept, et la bascule reste reversible huit jours.
